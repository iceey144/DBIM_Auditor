# DBIM Auditor

Automated compliance auditing framework for Government websites based on the Digital Brand Identity Manual (DBIM).

---

## Features

- Search compliance auditing
- Homepage structure validation
- Performance auditing
- Visual evidence generation
- Screenshot annotations
- Automated DOCX reports
- Playwright-based browser automation

---

## Tech Stack

- Python
- Playwright
- Pillow
- python-docx
- BeautifulSoup

---

## Installation

```bash
pip install -r requirements.txt

playwright install
```

---

## Usage

Run any auditor:

```bash
python search.py
```

```bash
python performance.py
```

```bash
python A4_1_2.py
```
